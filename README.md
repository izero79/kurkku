# Kurkku
Kurkku is simple card game for Windows 95/98/NT written with Visual Basic 5. I created this game back in 1998 and decided now to share the code as I found an old backup of it. At the time of writing this I was 19 years old and didn't have much experience in (Windows) Programming.

You can find the zip package of the game here:
https://tiedostot.apajalista.net/SGH/Windows/Kurkku/
